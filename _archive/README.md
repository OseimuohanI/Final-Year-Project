# Reversible workspace archives

The [17 November 2026 cleanup](cleanup-2026-11-17/README.md) preserves obsolete
source, early experiments and local development artifacts outside the active
project folders. Paths below each dated archive mirror their original paths,
including capitalization and hidden folders.

The archive is deliberately separate from the application. Do not add it to the
web server's document root, application imports or test discovery. Local-only
payloads remain ignored by Git; retain a separate private backup of this folder
if you need those artifacts on another computer.
