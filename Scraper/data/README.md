# Collected data

- `collections/`: successful collections and future scraper runs. Each run contains its raw records, import JSON, report, and `sources/` response/page captures when available.
- `collections/itel-power-station/`: the preserved first real dataset, containing 201 deduplicated reviews, its source captures, and dataset notes.
- `archive/`: the original failed HTTP pilots and the successful verification replay, retained for audit rather than mixed with the working dataset.

Run data is ignored by version control. Preserve a separate backup of research datasets and their provenance before changing or sharing them. Do not use archived failure reports as datasets.
